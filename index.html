The Council

Each model reads the repo from its own angle, they cross-examine each other, then the chair issues a verdict. Add one key or all three. Your keys go straight from this page to each provider, never anywhere else.

GitHub token (optional)

Without a token GitHub allows 60 requests per hour per IP. A token with no scopes raises that to 5,000 and unlocks your private repos if you grant access. It is sent only to api.github.com.

Key storage

Off by default: keys live in this tab's memory and vanish on refresh. Turn it on only on a computer you trust.

Privacy

  • No backend. This page is static HTML and JavaScript.
  • Network calls go only to api.github.com and the AI providers you add a key for. The page's Content-Security-Policy blocks everything else.
  • Repository text is sent to the AI providers when you convene the council. Do not use private code with providers you do not trust.
  • The whole app is one file you can read and fork.
